# Inheritance and Polymorphism

This directory contains Java programs demonstrating Inheritance and Method Overriding concepts using geometric shapes.

## Code Structure

- [`Bentuk.java`](./Bentuk.java) : Base class containing common attributes (`warna`).
- [`BujurSangkar.java`](./BujurSangkar.java) : Subclass representing a square (calculates area).
- [`Lingkaran.java`](./Lingkaran.java) : Subclass representing a circle (calculates area).
- [`Silinder.java`](./Silinder.java) : Subclass representing a cylinder (inherits from Lingkaran, calculates volume).
- [`Main.java`](./Main.java) : Main class to run and test all objects.
