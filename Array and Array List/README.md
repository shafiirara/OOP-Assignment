# Array and Array List

This directory contains Java programs that demonstrate Object-Oriented Programming (OOP) concepts, specifically managing dynamic collections of objects using `ArrayList`. The project models a basic bank application system where a bank manages multiple customers, and each customer can hold multiple bank accounts.

## Code Structure

- [`Account.java`](./Account.java) : Represents a bank account with basic transactions such as deposit and withdrawal.
- [`Customer.java`](./Customer.java) : Represents a bank customer that stores personal details and holds multiple `Account` objects.
- [`Bank.java`](./Bank.java) : Represents the bank system that manages a list of `Customer` objects using an `ArrayList`.
- [`Main.java`](./Main.java) : Main class to run and test bank operations, customer creation, account setup, deposits, and withdrawals.
